# Online Retail Analytics & Customer Purchase Prediction

An MCA lab project using the UCI Online Retail dataset. It includes data cleaning, exploratory data analysis, RFM customer segmentation, K-Means clustering, chronological purchase prediction, and a Streamlit dashboard.

## Modules
1. Data collection and cleaning
2. EDA: monthly revenue, top products, purchase frequency, country revenue
3. RFM analysis and K-Means customer segmentation
4. Logistic Regression and Random Forest for next-30-day purchase prediction
5. Streamlit interactive dashboard

## Dataset
UCI Machine Learning Repository — Online Retail (Dataset ID 352):  
https://archive.ics.uci.edu/dataset/352/online+retail

Please download the dataset from UCI and follow its attribution/licensing terms.

## Run locally
1. Install Python 3.10+.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Put the generated CSV files in `outputs/`:
   - `cleaned_online_retail.csv`
   - `customer_segments.csv`
   - `purchase_predictions.csv`
   - `model_results.csv`
4. Run:
   ```bash
   streamlit run app.py
   ```

## Important
The dashboard expects outputs generated by the Colab notebook. Model metrics are experimental and should not be interpreted as a guarantee of future performance. Customer segment names are heuristic interpretations of K-Means clusters.
